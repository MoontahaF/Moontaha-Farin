# Moontaha Farin — academic portfolio

A responsive, dependency-free static website. Open `index.html` locally to preview it.

## Publish options

- **GitHub Pages:** push this folder to a repository, then enable Pages from the repository settings.
- **Netlify:** drag this entire folder into Netlify Drop.
- **Cloudflare Pages / Vercel:** import a repository containing this folder; no build command is required.

All images, styles, and scripts are local. Update the content in `index.html`; the design lives in `styles.css`.
